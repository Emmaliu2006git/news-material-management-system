# Demo upload assets

These small files are generated locally for demonstrating file-material uploads.
They contain no third-party or copyrighted source media.

## Files

- `demo-field-image.png` is a 640 x 360 PNG illustration suitable for the image upload and AI-analysis flow.
- `demo-field-audio.wav` is a two-second mono PCM WAV recording made from generated tones.

Both files are well below the product's per-file and total upload limits.

## Upload them

1. Start the application and sign in.
2. Open an existing reporting project or create one.
3. Select **Add material**.
4. Select **File material**.
5. In **Files**, choose either demo file or select both.
6. Add a title and select **Create material**.

The audio file demonstrates ordinary file storage. The PNG also exercises the optional image-analysis path when that service is enabled.
